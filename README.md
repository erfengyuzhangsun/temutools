# Temu全托管卖家日常运营100%全自动化一站式平台

## 🚀 平台概述

基于原有Temu跨境卖家利润核算工具，全面升级为**全托管卖家日常运营全自动化一站式平台**。  
涵盖从API数据同步 → 核价自动化 → 库存管理 → 数据分析预警 → 智能调价 → 财务结算 → 多店铺总控 → 消息售后 → 风控体检 → 选品供应链的**完整运营闭环**。

> **核心理念**：卖家每天只需5分钟查看告警待办，其余全部自动化。

## ✨ 核心功能（16大模块）

### P0 🔥 底层底座
| 模块 | 功能 |
|------|------|
| **1. API对接与数据同步** | 自动实时同步Temu订单/库存/核价/结算/活动/消息；多店铺统一管理；数据加密传输存储 |
| **2. 核价自动化模块** | 自定义毛利率阈值；批量自动判断接受/拒绝核价；活动商品独立阈值；超时自动弹窗提醒 |
| **3. 全局定时任务调度中心** | 统一管理所有自动化任务；可视化配置周期/启停/重试次数；完整执行日志与故障告警 |

### P1 ⭐ 核心运营
| 模块 | 功能 |
|------|------|
| **4. 库存智能管理** | 实时库存同步；安全库存告警；智能补货建议；滞销SKU自动识别 |
| **5. 数据自动分析与预警** | 核心指标定时采集；转化率/退货率阈值告警；AI诊断建议；自动生成日报/周报 |

## 📦 快速开始

### 环境要求
- Python 3.10+
- pip / conda

### 一键安装

```bash
# Windows
deploy.bat

# Linux/Mac
chmod +x deploy.sh && ./deploy.sh
```

### 手动安装

```bash
# 1. 克隆项目
git clone <your-repo-url>
cd temu_tools

# 2. 安装依赖
pip install -r requirements.txt
pip install pytest pytest-asyncio cryptography freezegun

# 3. 启动应用
python -m streamlit run app.py --server.port 8501

# 4. 启动API代理（可选）
python -m uvicorn api.index:app --host 0.0.0.0 --port 8000
```

### 访问
- **主应用**：http://localhost:8501
- **API健康检查**：http://localhost:8000/health
- **默认密码**：`admin123`

## 🔒 安全特性

- **API密钥加密**：使用Fernet对称加密存储，日志脱敏
- **多店铺数据隔离**：user_id+shop_id双层隔离
- **传输加密**：全HTTPS通信
- **参数化查询**：杜绝SQL注入
- **异常隔离**：模块崩溃不影响主系统

# 鲸云策 — 客户绑店操作指南

> **适用对象**：Temu 跨境卖家（中国籍经营者，含全托管、半托管、Y2 等模式）  
> **平台地址**：https://www.jinpuhuang.com  
> **最后更新**：2026-05-18

---

## 写在前面

鲸云策是 Temu 开放平台上的**认证开发者工具**，帮助您管理店铺订单、库存、核价等数据。

- 您**不需要**成为 Temu 开发者，也**不需要**自己的 App Key。  
- 全托管、半托管、Y2 等店铺，**绑店步骤相同**。  
- 使用前请用**店铺主账号**操作（子账号可能无授权权限）。

如有疑问，请联系客服微信：**returnHuangMuNing**

## 二、整体流程（3 大步）

```
第 1 步  在鲸云策注册并同意协议
    ↓
第 2 步  在 Temu 卖家后台授权应用「鲸云策」
    ↓
第 3 步  回到鲸云策绑定店铺 → 开始使用
```

---

## 三、第 1 步：注册鲸云策

1. 打开 https://www.jinpuhuang.com  
2. 点击 **登录** → 切换到 **注册**  
3. 填写邮箱、密码（至少 6 位）  
4. **勾选**《用户服务协议》和《隐私政策》（可点击链接阅读）  
5. 注册成功后自动进入系统  

**说明**：您的数据将按隐私政策存储于安全云服务器（含境外节点），注册即表示您已知情并同意。

---

## 四、第 2 步：在 Temu 授权「鲸云策」

### 4.1 登录跨境卖家后台

根据您的店铺区域选择入口（多数中国跨境卖家为**美国站**）：

| 区域 | 授权入口 |
|------|----------|
| **美国**（最常见） | https://agentseller.temu.com/open-platform/system-manage/client-manage |
| **欧洲** | https://agentseller-eu.temu.com/open-platform/system-manage/client-manage |

> 请使用您日常管理 Temu 店铺的后台地址；全托管、半托管、Y2 店铺均从此类**跨境卖家后台**进入。

### 4.2 完成授权

1. 使用 **店铺主账号** 登录  
2. 进入 **开放平台** → **客户端管理**（或「应用授权」类似菜单）  
3. 找到应用 **「鲸云策」**（或运营者告知的应用名称）  
4. 点击 **授权 / 同意**  
5. 页面会显示 **Access Token（访问令牌）**  
6. **完整复制** 该 Token（不要漏字符、不要多空格）  

**重要提示：**

- Token 有效期约 **3 个月**，到期后需重新授权并重新绑店。  
- 请勿把 Token 发给无关人员；仅用于绑定您自己的店铺。  
- 若找不到「鲸云策」，请联系客服确认应用是否已上架。

---

## 五、第 3 步：在鲸云策绑定店铺

1. 登录 https://www.jinpuhuang.com  
2. 左侧菜单进入 **API 同步**（专业版及以上套餐，具体以您账号为准）  
3. 点击 **绑定店铺**  
4. 填写：  

| 字段 | 填写说明 |
|------|----------|
| 店铺名称 | 自定义备注，如「张三美国店」 |
| Access Token | 粘贴第 2 步复制的令牌 |
| 区域 | 美国店选 **美国 (us)**；欧洲店选 **欧洲 (eu)**；全球店选 **全球 (global)** |

5. **勾选**底部声明：  
   > 确认本人有权操作该店铺；已在 Temu 完成官方授权；同意鲸云策按隐私政策处理店铺数据。  
6. 点击确定，提示 **绑定成功**  

### 5.1 验证是否成功

在 **API 同步** 列表中能看到您的店铺 → 点击 **同步订单** → 若有数据返回或提示成功，说明绑定正常。

---

## 六、多个店铺怎么绑？

- **一个 Temu 店铺 = 绑定一次**（各授权、各填一次 Token）。  
- 全托管店、半托管店、Y2 店：**操作相同**，只是店铺名称和 Token 不同。  
- 在鲸云策可在一个账号下管理多店（数据按账号隔离，互不可见）。

---

## 七、可选：一键授权链接

若客服发给您一条 **授权链接**（而非让您自己复制 Token）：

1. 在鲸云策 **API 同步** → **一键授权** → 按提示生成或直接使用客服给的链接  
2. 用浏览器打开链接，登录 Temu 卖家账号并同意授权  
3. 授权成功后会自动跳回鲸云策，店铺自动绑定  

> 部分跨境店铺仅支持「手动复制 Token」方式；若链接不可用，请按 **第四、五节** 手动绑店。

## 八、常见问题

### Q1：找不到「鲸云策」应用？

应用可能尚在 Temu 审核。请联系客服微信 **returnHuangMuNing** 确认是否可授权。

### Q2：绑定失败 / Token 无效？

- 检查 Token 是否复制完整  
- 确认区域（美国/欧洲/全球）与店铺一致  
- 在 Temu 后台重新授权，获取新 Token 后再绑  

### Q3：全托管和半托管绑法一样吗？

**一样。** 区别在平台履约规则，不在绑店步骤。核价、利润等功能在系统内按您的模式使用即可。

### Q4：数据安全吗？

- 传输全程 HTTPS 加密  
- 凭证加密存储  
- 仅用于您授权的店铺功能  
- 详情见网站《隐私政策》  

### Q5：如何取消授权？

1. **鲸云策**：API 同步中删除店铺绑定  
2. **Temu**：卖家后台 → 客户端管理 → 取消对「鲸云策」的授权  

### Q6：套餐到期怎么办？

联系客服微信续费；到期后部分功能将不可用，数据保留规则见《用户服务协议》。

# Temu 开放平台 API 凭证获取指南

> 本文档供 **Temu 卖家** 使用，指导如何获取 API 凭证并安全地提供给系统。
> **全程仅需 5 分钟**，不需任何开发知识。

---

## 1. 什么是 API 凭证？

API 凭证就像一把 **电子钥匙**，让工具可以代表你的店铺安全地读取数据。

你需要提供两个值：

| 名称 | 说明 | 示例 |
|------|------|------|
| `app_key` | 应用公钥（相当于账号） | `abc123xyz` |
| `app_secret` | 应用密钥（相当于密码） | `sk_xxxxxxxxxxxxxxxx` |

> ⚠️ **安全提示**：`app_secret` 请勿泄露给无关人员。本工具会加密存储，其他人即使登录数据库也看不到明文。

---

## 2. 获取步骤（截图指引）

### 第 1 步：进入开放平台

打开 Temu 卖家后台 → 找到 **「开放平台」** 或 **「服务市场」** → **「应用管理」**

> 路径推测（因 Temu 界面可能调整）：
> ```
> 商家中心 → 设置 → 开放平台 → 应用管理
> ```
> 或
> ```
> 商家中心 → 服务市场 → 我的应用 → 创建应用
> ```

### 第 2 步：创建应用

1. 点击 **「创建应用」** 或 **「新增应用」**
2. 填写应用名称（如：`运营辅助工具`）
3. 选择需要的 **API 权限**（建议勾选全部，由系统按需调用）：
   - ✅ 订单管理
   - ✅ 商品管理
   - ✅ 库存管理
   - ✅ 核价管理
   - ✅ 结算管理
   - ✅ 消息管理
   - ✅ 活动管理
4. 提交创建

### 第 3 步：获取凭证

创建成功后，在应用详情页找到：

```
App Key（应用Key）：   xxxxxx
App Secret（应用Secret）： xxxxxx
```

### 第 4 步：配置 IP 白名单（如需要）

部分平台要求设置 IP 白名单才能调用 API。如果遇到此提示，请添加以下服务器 IP：

```
你的服务器 IP 地址（联系管理员获取）
```

## 3. 安全注意事项

### ✅ 本系统的安全措施

| 措施 | 说明 |
|------|------|
| 加密存储 | API Secret 使用 Fernet 加密后存入数据库，明文不出内存 |
| 日志脱敏 | 所有日志打印时自动隐藏密钥中间部分（如 `sk_******xyz`） |
| 传输加密 | API 调用全部走 HTTPS，数据在传输中加密 |
| 数据隔离 | 不同店铺的凭证互不可见，user_id + shop_id 双层隔离 |

### ❌ 您需要注意

- `app_secret` 相当于密码，**不要截图发送、不要写在聊天记录中**
- 建议在工具内绑定后，**在 Temu 开放平台定期轮换密钥**
- 如需测试，可使用 Temu 提供的 **沙箱环境** 凭证（如果有）

## 4. 常见问题

### Q: 我找不到「开放平台」入口怎么办？
A: 不同版本的 Temu 卖家后台可能位置不同，可以尝试：
- 搜索「开放平台」或「API」
- 联系 Temu 客服或您的运营经理
- 截图商家后台给系统管理员协助查找

### Q: 创建应用需要审核吗？
A: 通常即时生效，部分权限可能需要平台审核（几分钟~几小时）。

### Q: 一个店铺可以创建多个应用吗？
A: 通常可以。建议为本工具单独创建一个应用，方便后续管理。

### Q: 这些 API 是免费的吗？
A: Temu 开放平台 API 通常是免费的，但可能有调用频率限制（如每分钟 100 次）。

### Q: 调用 API 会扣费吗？
A: 通常不扣费。如果有计费政策，Temu 官方会明确告知。

---

## 5. 获取凭证后

拿到 `app_key` 和 `app_secret` 后：

1. 登录系统 → **「API对接与数据同步」**
2. 点击 **「绑定店铺」**
3. 填写：**店铺名称** + **App Key** + **App Secret**
4. 点击绑定，系统会加密存储并自动测试连通性

> 绑定成功后，预设的自动任务（同步订单、核价处理等）就可以真正工作了。

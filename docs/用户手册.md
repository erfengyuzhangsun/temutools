## 1. 快速入门

### 1.1 登录系统
1. 浏览器打开 http://www.jinpuhuang.com
2. 输入客服提供给您的**访问密码**
3. 勾选「我已阅读并同意《隐私政策》」
4. 点击「验证身份」进入系统

### 1.2 首次使用步骤

```
第1步：进入「API对接与数据同步」→ 绑定店铺（需要向客服获取 Temu API 凭证）
第2步：绑定成功后，手动触发一次「同步订单」
第3步：进入「定时任务调度中心」→ 启用预设的自动任务
第4步：按需使用其他功能模块
```

### 1.3 界面导航
登录后左侧为侧边栏导航，按功能区分为：
- **核心工具**：利润分析、多店铺大屏、API同步、核价自动化、定时任务
- **运营管理**：库存管理、数据分析、智能调价、财务对账、标签发货
- **风控 & 自动化**：消息售后、活动报名、风控体检、批量运营、差评监控、选品辅助、供应商管理

## 2. 模块使用指南

### 2.1 API对接与数据同步
> 数据存于数据库，关闭页面不丢失

**功能**：绑定店铺并同步 Temu 订单/核价/结算数据

| 操作 | 说明 |
|------|------|
| 绑定店铺 | 填写店铺名称、API Key、API Secret（加密存储），点击「绑定店铺」 |
| 同步订单 | 选择已绑定的店铺 → 选择同步方式 → 点击「同步」 |
| 同步历史 | 查看每次同步的耗时、新增数、错误信息 |

**数据持久化**：店铺凭证加密存于数据库，每次登录自动读取，无需重复绑定。

### 2.2 核价自动化
> 数据存于数据库，关闭页面不丢失

**功能**：自动检查核价通知，根据毛利率阈值自动接受或拒绝

| 操作 | 说明 |
|------|------|
| 设置阈值 | 调整毛利率阈值，低于此值自动拒绝 |
| 执行自动核价 | 点击「执行自动核价」，系统扫描所有核价通知并处理 |
| 查看日志 | 查看每次核价处理的详细记录 |

### 2.3 定时任务调度中心（预设自动任务）
> 任务定义存于数据库，但调度器在页面加载时自动注册

**预设任务（开箱即用，无需配置）：**

| 任务名称 | 默认执行频率 | 说明 |
|---------|-------------|------|
| 自动同步订单 | 每6小时 | 从 Temu API 同步所有店铺的最新订单 |
| 自动核价处理 | 每3小时 | 自动检查并处理核价通知 |
| 自动库存同步 | 每4小时 | 同步库存数据，识别低库存/高库存SKU |
| 自动风控体检 | 每天9:00 | 对全店SKU进行合规检查 |
| 自动差评同步 | 每8小时 | 同步最新差评并预警 |

**操作说明：**
- 进入该页面时，预设任务自动注册
- 到期的任务会自动执行（页面加载时检查并触发）
- 可手动点击「立即执行一次」随时触发任何任务
- 可修改每个任务的 Cron 执行频率
- 可暂停/启用任务

> ⚠️ 注意：自动执行只在您访问此页面时触发。如果您需要24/7后台自动运行，请联系客服配置服务器守护进程。

## 3. 数据持久化说明

### 3.1 哪些数据会持久化（存在数据库，关页面不丢失）

| 数据类型 | 存哪里 | 什么时候消失 |
|---------|-------|------------|
| 店铺绑定信息（含API凭证） | MySQL数据库（加密存储） | 手动解绑 |
| 同步的订单数据 | MySQL数据库 | 不过期 |
| 库存数据 | MySQL数据库 | 不过期 |
| 结算/财务数据 | MySQL数据库 | 不过期 |
| 核价日志 | MySQL数据库 | 不过期 |
| 调价历史 | MySQL数据库 | 不过期 |
| 活动报名记录 | MySQL数据库 | 不过期 |
| 供应商信息 | MySQL数据库 | 手动删除 |
| 定时任务定义 | MySQL数据库 | 手动注销 |
| 执行日志 | MySQL数据库 | 长期保留 |
| 用户账户信息 | MySQL数据库 | 套餐过期 |

### 3.2 哪些数据不持久化（每次打开都是默认值）

| 数据类型 | 说明 |
|---------|------|
| 核价阈值设置 | 每次进入页面显示默认值70%，关闭即重置 |
| 库存告警阈值 | 默认值，不保存用户个人设置 |
| Cron表达式修改 | 修改后存于内存，页面刷新后恢复为预设默认值 |
| 批量运营输入的SKU列表 | 每次需重新填写 |
| 选品采集结果 | 采集结果展示后刷新即消失，建议导出CSV |

### 3.3 登录状态

| 事项 | 说明 |
|------|------|
| 登录有效期 | 7天自动过期 |
| 关浏览器 | 登录状态消失，需要重新输入密码 |
| 多设备登录 | 支持，但每个设备需要单独登录 |

## 5. 常见问题 FAQ

### Q1: 为什么我重新登录后店铺还在？
店铺绑定信息存在数据库中（加密存储），只要不解绑，永久有效，无需重复绑定。

### Q2: 定时任务真的会自动执行吗？
预设任务会在您打开「定时任务调度中心」页面时，自动检查哪些任务到期并执行。如果您希望 24/7 都在后台自动运行，请联系客服配置服务器守护进程。

### Q3: 我的API密钥安全吗？
API密钥使用 Fernet 对称加密存储在数据库中，日志中自动脱敏，只有系统运行时才能解密使用。

### Q4: 一个用户可以绑定几个店铺？
不限数量。每个店铺需要独立的 Temu API 凭证。

### Q5: 为什么收款码图片显示不了？
如果图片加载失败，可能是网络问题，请刷新页面重试。如果持续失败，请联系客服获取付款方式。

### Q6: 数据会丢失吗？
系统每天早上自动备份数据库。即使服务器出问题，也可以从备份恢复。

### Q7: 套餐过期会怎样？
套餐过期后无法登录系统。请联系客服续费。

### Q8: 核价阈值设置了为什么下次进来又变回默认？
当前版本阈值设置不保存到数据库，每次进入页面使用默认值。后续版本会支持持久化保存。

### Q9: 忘记密码了怎么办？
联系客服微信：**returnHuangMuNing**，由管理员重置密码。

### Q10: 支持手机端使用吗？
系统可在手机浏览器中打开使用，但最佳体验建议使用电脑端。
